#  Exercício de Programação Orientada a Objetos em Java

##  Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aplicar os conceitos fundamentais da Programação Orientada a Objetos (POO) utilizando a linguagem Java.

A atividade consiste na modelagem de objetos do mundo real por meio da criação de classes, atributos, construtores, métodos, getters e setters, seguindo as convenções e boas práticas da linguagem Java.

Além da criação das classes, foi desenvolvido um programa principal responsável por instanciar os objetos e executar seus métodos, permitindo visualizar na prática o relacionamento entre as entidades criadas.

---

##  Objetivos

* Aplicar os conceitos de Programação Orientada a Objetos;
* Criar classes representando objetos do mundo real;
* Implementar atributos privados (encapsulamento);
* Utilizar construtores para inicialização dos objetos;
* Implementar métodos getters e setters;
* Instanciar objetos e executar métodos em uma aplicação principal.
